# SBND flashes from reco1 OpHits: `SBNDOpFlashFinder`

`SBNDOpFlashFinder` (`flash/src/SBNDOpFlashFinder.cxx`, code by xning, brought in 2026-09-24) rebuilds
optical flashes from SBND's reco1 PMT `recob::OpHit`s, per TPC, instead of taking the reco1
`recob::OpFlash`.  SBND's `SimpleFlashAlgo` integrates 8 µs after the brightest seed and vetoes ±8 µs,
so two real flashes closer than that in one TPC become one; this finder keeps the 8 µs accumulator
but adds an explicit pulse split, a join of tail pieces, larana late-light removal and SBND's prompt
flash time.  Its C++ defaults ARE the SBND settings.  Input: an `ITensorSet` holding an `ophits`
tensor `[nhit, 9]` (channel, time, width, area, amplitude, PE, start, flash id, fast/total) as
`SBNDReco1OpHitSource` (repo `wire-cell-sbnd-reco1`) writes it.  Output: `opflash [nflash, 1+nchan]`,
`flash_summary`, `ophits` (with flash ids), set metadata passed through (`run`, `subrun`, `event`,
`frame_apply_at_caf`) — a drop-in for the `opflash_apa<N>.tar.gz` the SBND Q/L matching job reads.

Tests: `flash/test/doctest_sbndopflashfinder.cxx` (13 cases, `./build/flash/wcdoctest-flash`).

The investigation, the campaign and its gates: `wcp-porting-validation`
`sbnd/sbnd_xin/docs/123_sbnd-ophit-flash-reco-campaign.md`.
